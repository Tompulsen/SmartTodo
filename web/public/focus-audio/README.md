# Focus Audio Assets

The WAV loops are original synthesized ambience and a generated music-box phrase,
not field recordings. Rebuild with `scripts/create-focus-sounds.py` (Python stdlib).

The PNG covers are original geometric artwork generated by
`scripts/create-public-art.ps1`. They are distributed under this repository's
MIT License. Reference screenshots and their cropped illustrations are not
part of this public edition.

Uploaded audio is separate from these assets and is stored only in the current
browser's IndexedDB. No files are sent to a remote service.
